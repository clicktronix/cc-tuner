## Repository rule loading

Before reviewing or editing, read this repository's applicable instruction files and rule bodies.
Follow its rule index when present; also inspect `.claude/rules/**/*.md` for newly added rules.
Read rules without `paths` and rules covering the intended files or behaviour, including new files.
Follow relevant documentation links and repeat discovery when scope expands or another repository
is involved. Read that repository's own instructions first. Do not count filenames or summaries as
loaded rules. Use the installed `agent-rules` skill when available; these requirements also apply
without the plugin. Preserve the repository's existing rule ownership and precedence.
